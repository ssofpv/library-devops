# API книг

## Поля

| Поле | Описание |
|---|---|
| id | Автоматический идентификатор |
| title | Обязательное название, максимум 300 символов |
| publication_year | Необязательный год от 1 до 32767 или null |
| author_ids | Необязательный список идентификаторов существующих авторов |

Пробелы по краям названия удаляются.
Пустое название и название из пробелов запрещены.
Повторяющиеся идентификаторы авторов запрещены.

## Операции

| Метод | Адрес | Действие | Успешный ответ |
|---|---|---|---|
| GET | /api/books/ | Список книг | 200 |
| POST | /api/books/ | Создание | 201 |
| GET | /api/books/{id}/ | Просмотр книги | 200 |
| PUT | /api/books/{id}/ | Обновление книги | 200 |
| PATCH | /api/books/{id}/ | Частичное обновление | 200 |
| DELETE | /api/books/{id}/ | Удаление | 204 |

Вместо {id} указывается идентификатор книги.

## Пример создания

POST /api/books/

```json
{
  "title": "Мастер и Маргарита",
  "publication_year": 1967,
  "author_ids": [1]
}
```

Указанный автор должен существовать.

## Изменение авторов

Переданный author_ids заменяет список авторов книги.

Пустой список author_ids удаляет все связи книги с авторами.
Сами авторы при этом сохраняются.

Если при PATCH поле author_ids отсутствует,
существующие связи сохраняются.

Чтобы убрать год издания, передайте publication_year: null.

## Ошибки

- 400 — неправильные поля или идентификаторы авторов.
- 404 — книга не найдена.
- 409 — удаление заблокировано защищёнными связанными записями.

Ошибка валидации возвращается по имени соответствующего поля.
Некорректный запрос не должен частично изменять книгу.

## Удаление

Удаление книги не удаляет её авторов.

Связь Copy.book использует on_delete=PROTECT.
Удаление книги с экземплярами через API возвращает 409.
Книга, её связи с авторами и экземпляры сохраняются.
Это поведение покрыто интеграционным тестом
в inventory/test_copies_api.py.


## Доступ

Для всех операций нужен вход через /accounts/login/. Используется сессия Django; без входа API возвращает 403. Для POST, PUT, PATCH и DELETE с сессией требуется CSRF-токен. См. [Аутентификация](authentication.md).
