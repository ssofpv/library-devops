# API филиалов

## Поля

| Поле | Описание |
|---|---|
| id | Автоматический идентификатор |
| name | Обязательное название, максимум 200 символов |
| address | Обязательный адрес, максимум 500 символов |

Пробелы по краям названия и адреса удаляются.
Пустые значения и строки из пробелов запрещены.

## Операции

| Метод | Адрес | Действие | Успешный ответ |
|---|---|---|---|
| GET | /api/branches/ | Список филиалов | 200 |
| POST | /api/branches/ | Создание | 201 |
| GET | /api/branches/{id}/ | Просмотр одного филиала | 200 |
| PUT | /api/branches/{id}/ | Полное обновление | 200 |
| PATCH | /api/branches/{id}/ | Частичное обновление | 200 |
| DELETE | /api/branches/{id}/ | Удаление | 204 |

Вместо {id} указывается идентификатор филиала.

## Пример создания

POST /api/branches/

```json
{
  "name": "Центральный",
  "address": "ул. Ленина, 10"
}
```

## Ошибки

- 400 — отсутствующее, пустое или слишком длинное поле.
- 404 — филиал не найден.

При ошибке валидации ответ содержит имя поля и список сообщений.
Некорректное обновление не изменяет сохранённые данные.
