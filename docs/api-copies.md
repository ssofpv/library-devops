# API экземпляров

Экземпляр — одна физическая книга, размещённая в одном филиале.

## Поля

| Поле | Описание |
|---|---|
| id | Автоматический идентификатор, только чтение |
| inventory_number | Обязательная строка, максимум 100 символов, уникальна |
| book_id | Обязательный идентификатор существующей книги |
| branch_id | Обязательный идентификатор существующего филиала |

Пробелы по краям инвентарного номера удаляются.
Пустой номер и номер из пробелов запрещены.

## Операции

| Метод | Адрес | Действие | Успешный ответ |
|---|---|---|---|
| GET | /api/copies/ | Список | 200 |
| POST | /api/copies/ | Создание | 201 |
| GET | /api/copies/{id}/ | Просмотр | 200 |
| PUT | /api/copies/{id}/ | Полное обновление | 200 |
| PATCH | /api/copies/{id}/ | Частичное обновление | 200 |
| DELETE | /api/copies/{id}/ | Удаление | 204 |

## Создание

POST /api/copies/

```json
{
  "inventory_number": "INV-001",
  "book_id": 1,
  "branch_id": 1
}
```

Указанные книга и филиал должны существовать.

## Перемещение в другой филиал

PATCH /api/copies/{id}/

```json
{
  "branch_id": 2
}
```

Филиал должен существовать.
Остальные поля при таком запросе сохраняются.

## Фильтрация списка

- /api/copies/?book_id=1
- /api/copies/?branch_id=2
- /api/copies/?book_id=1&branch_id=2

При двух фильтрах применяются оба условия одновременно.
Без фильтров возвращаются все экземпляры в порядке id.

Значения фильтров — целые числа от 1 до 9223372036854775807.
Неверный формат или значение вне диапазона возвращает 400.
Корректный идентификатор без совпадений возвращает пустой список
и статус 200.

Фильтры применяются только к операции получения списка.

## Ошибки

- 400 — неверные поля, занятый инвентарный номер,
  несуществующая книга или филиал при записи,
  некорректные параметры фильтрации.
- 404 — запрошенный экземпляр не найден.

При ошибке валидации изменения экземпляра не сохраняются.

## Связи и удаление

Copy.book и Copy.branch используют on_delete=PROTECT.

Удаление книги или филиала с экземплярами через API возвращает 409.
Книга, филиал и экземпляры при отказе сохраняются.
Защита также действует при удалении через Django ORM.

Удаление экземпляра не удаляет книгу или филиал.
После удаления последнего экземпляра книгу и филиал можно удалить.

## Доступ

Для всех операций нужен вход через /accounts/login/. Используется сессия Django; без входа API возвращает 403. Для POST, PUT, PATCH и DELETE с сессией требуется CSRF-токен. См. [Аутентификация](authentication.md).
