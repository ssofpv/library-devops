# HTTP API

## Авторы

### Поля

| Поле | Описание |
|---|---|
| id | Идентификатор, назначается автоматически |
| full_name | Обязательное имя, от 1 до 200 символов после удаления пробелов по краям |

### Операции

| Метод | Адрес | Действие | Успешный ответ |
|---|---|---|---|
| GET | /api/authors/ | Получить список | 200 |
| POST | /api/authors/ | Создать автора | 201 |
| GET | /api/authors/{id}/ | Получить автора | 200 |
| PUT | /api/authors/{id}/ | Обновить данные автора | 200 |
| PATCH | /api/authors/{id}/ | Частично обновить данные | 200 |
| DELETE | /api/authors/{id}/ | Удалить автора без книг | 204 |

Вместо {id} указывается идентификатор автора.

### Пример создания

POST /api/authors/

```json
{
  "full_name": "Михаил Булгаков"
}
```

Пример ответа:

```json
{
  "id": 1,
  "full_name": "Михаил Булгаков"
}
```

Идентификатор в реальном ответе может отличаться.

### Ошибки

- 400 — некорректные данные: отсутствующее, пустое или слишком длинное имя.
- 404 — автор с указанным идентификатором не найден.
- 409 — попытка удалить автора, связанного с книгами.

При ошибке проверки имени ответ содержит поле full_name
со списком сообщений.

При запрещённом удалении:

```json
{
  "code": "author_has_books",
  "message": "Нельзя удалить автора, связанного с книгами."
}
```

Автор, книги и связи при таком отказе сохраняются.

Ограничение удаления реализовано в HTTP API.
Прямое удаление через ORM этим обработчиком не защищено.

### Доступ

Для всех операций нужен вход через /accounts/login/. Используется сессия Django; без входа API возвращает 403. Для POST, PUT, PATCH и DELETE с сессией требуется CSRF-токен. См. [Аутентификация](authentication.md).
