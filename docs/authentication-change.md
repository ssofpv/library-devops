## Перенос в ваш существующий репозиторий

1. Создайте Issue на GitHub. Сохраните текущую работу; рабочее дерево должно быть чистым.
2. Обновите main и создайте `git switch -c feat/authentication`.
3. Из каталога вашего репозитория выполните `git apply --check /путь/authentication.patch`,
   затем `git apply /путь/authentication.patch`. Патч подготовлен к b6d6956;
   если main изменился, сначала разберите конфликт, не применяйте принудительно.
   Архив содержит также полное дерево исходников для сравнения, без .git и локальной БД.
4. Добавьте обновлённые Word-документы из папки documents комплекта в docs/submission/.
5. Выполните `make migrate`, создайте учётную запись, `make verify` и ручной сценарий.
6. Разделите изменение на осмысленные коммиты: реализация и тесты; документация.
   Перед каждым коммитом просмотрите `git diff --cached` и `git diff --cached --check`.
7. Отправьте ветку, откройте PR со ссылкой на Issue; дождитесь review второго участника
   и CI на Python 3.13/3.14. Только затем сливайте в main.
8. Сохраните скриншоты новых проверок и демонстрации. Старый v0.1.0 не перемещайте.
   Если нужен тег готовой версии, создайте согласованный новый тег после слияния.
