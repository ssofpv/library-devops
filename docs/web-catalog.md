# Веб-интерфейс каталога

Исполнитель: Макарычева С. А. Проверяющая: Скрынникова П. А.

После `make run` откройте http://127.0.0.1:8000/.
Нужен локальный .env с DJANGO_DEBUG=true для раздачи оформления сервером разработки.

## Страницы

| Адрес | Назначение |
|---|---|
| / | Главная страница и количество записей |
| /authors/ | Список авторов |
| /authors/new/ | Создание автора |
| /authors/{id}/edit/ | Изменение автора |
| /authors/{id}/delete/ | Подтверждение удаления автора |
| /books/ | Список книг с именами авторов и годом |
| /books/new/ | Создание книги |
| /books/{id}/edit/ | Изменение книги |
| /books/{id}/delete/ | Подтверждение удаления книги |

Формы работают с той же базой, что и HTTP API. После сохранения открывается
список записей с сообщением об успехе. Ввод пользователя экранируется в HTML.
Авторизация отсутствует: это локальное учебное приложение.

## Правила

- Имя автора: обязательная строка, не более 200 символов.
- Название книги: обязательная строка, не более 300 символов.
- Строки из пробелов отклоняются, крайние пробелы удаляются.
- Год необязателен; допустимо целое число от 1 до 32767.
- Авторов можно выбрать несколько или не выбирать.
- При ошибке данные не сохраняются, форма показывает причину.
- GET страницы удаления только показывает подтверждение.
- Удаление выполняется POST-запросом с CSRF-токеном.
- Автора с книгами удалить нельзя; POST возвращает 409.
- Книгу с экземплярами удалить нельзя; POST возвращает 409.

Защита удаления автора находится в обработчиках API и веб-формы.
Прямое удаление автора через ORM этим ограничением не защищено.

## Библиотечный фонд

Страницы филиалов и экземпляров используют общий шаблон
`catalog/templates/library/base.html` и `catalog/static/library/site.css`.
[Описание страниц фонда](web-inventory.md).

## Проверка на компьютере участницы

1. Выполнить `make verify`.
2. Запустить `make run` и открыть главную страницу.
3. Добавить автора «Жюль Верн» и книгу «Двадцать тысяч лье под водой», год 1870.
4. Убедиться, что книга появилась в списке и доступна через /api/books/.
5. Изменить книгу; проверить сохранение года и авторов.
6. Отправить пустое имя и неверный год; убедиться, что видны ошибки.
7. Попробовать удалить автора с книгой: получить понятный отказ.
8. Для существующей книги с экземпляром проверить отказ удаления.
9. Удалить книгу без экземпляров, затем автора без книг.
10. Проверить удобство страницы при узком окне браузера.

Это сценарий для выполнения, а не утверждение о пройденной ручной проверке.
