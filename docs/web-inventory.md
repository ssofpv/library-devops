# Веб-интерфейс филиалов и экземпляров

Исполнитель: Скрынникова П. А. Проверяющая: Макарычева С. А.

После `make run` открыть http://127.0.0.1:8000/.
В меню доступны «Филиалы» и «Экземпляры».
Нужен включённый DJANGO_DEBUG для локальной раздачи оформления.

| Адрес | Назначение |
|---|---|
| /branches/ | Названия и адреса филиалов |
| /branches/new/ | Создание филиала |
| /branches/{id}/edit/ | Изменение названия и адреса |
| /branches/{id}/delete/ | Подтверждение удаления |
| /copies/ | Экземпляры, книги и места хранения |
| /copies/new/ | Добавление экземпляра |
| /copies/{id}/edit/ | Изменение номера, книги или филиала |
| /copies/{id}/delete/ | Подтверждение удаления |

Фильтры страницы /copies/ передаются параметрами book и branch, например
/copies/?book=1&branch=2. Пустой выбор означает «Все». Несуществующее или
неправильное значение возвращает страницу с ошибкой и HTTP 400.
Параметры HTTP API остаются прежними: book_id и branch_id; пустые значения
в API по-прежнему отклоняются. HTML-форма и API имеют разный формат запросов.

## Ограничения

Название и адрес филиала обязательны, длина — до 200 и 500 символов.
Инвентарный номер обязателен, до 100 символов, уникален среди всех экземпляров.
Крайние пробелы удаляются. Значения из одних пробелов не принимаются.
Книга и филиал выбираются из существующих записей.
Ошибки формы отображаются на русском; неверная форма не изменяет данные.
При изменении филиала у экземпляра меняется его место хранения.
Филиал с экземплярами не удаляется (POST возвращает 409).
GET страницы удаления ничего не удаляет; POST защищён CSRF-токеном.
Все страницы требуют входа. Без сессии выполняется перенаправление на /accounts/login/.
Перед ручным сценарием войдите под учётной записью сотрудника.
[Вход и выход](authentication.md).

## Сценарий ручной проверки

Это план проверки, а не заранее заполненные результаты.

1. Создать филиалы «Центральная библиотека» (ул. Лесная, 10) и
   «Южная библиотека» (ул. Полевая, 2).
2. В разделе «Экземпляры» создать запись LIB-001, выбрать имеющуюся книгу
   и Центральную библиотеку. Если номер уже занят, взять свободный.
3. Проверить фильтры отдельно по книге и филиалу, вместе и кнопку «Сбросить».
4. Создать второй экземпляр с тем же номером — получить ошибку, без новой записи.
5. Попробовать удалить Центральную библиотеку — получить отказ, экземпляр сохранён.
6. Через «Изменить» перенести экземпляр в Южную библиотеку.
   Проверить новый филиал в списке и через фильтры.
7. Проверить запрет удаления соответствующей книги в разделе «Книги».
8. Удалить тестовый экземпляр. Проверить, что книга и филиал остались.
9. Удалить пустой тестовый филиал.
10. Проверить пустые обязательные поля и страницы в узком окне браузера.

Автоматические проверки: make verify. Новые тесты: inventory/test_web.py.
